The whole internet described in a single word, written to `/output/entry.txt`. The word: **brainrot** — the funniest single word that says something true about the internet as a whole, judged two entries at a time by a model on make.fun's "The Internet in One Word" bounty ($10, free to enter, no files).

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
